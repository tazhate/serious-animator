# serious-animator

Плагин Claude Code, который делает из одной фразы рисованный ролик с озвучкой: доска, маркер, иконки появляются ровно в тот момент, когда диктор о них говорит.

```
/serious-animator:animate Как работает DNS
```

Идея взята у [ashishjamarkattel/Animator](https://github.com/ashishjamarkattel/Animator). Там сценарий, картинки, голос и разметку регионов делает Gemini, а Python-движок угадывает по растровой картинке, как ее рисовать. Здесь иначе. Сценарий и сцены пишет Claude прямо в сессии, сцены сразу векторные (SVG), поэтому каждый штрих рисуется по своей настоящей траектории. Голос дает edge-tts, по одному клипу на фразу, так что границы между фразами известны точно, а не вычисляются по паузам. Рендер и кодирование - один бинарь на Go.

Что изменилось относительно оригинала и почему, разобрано в [docs/REVIEW.md](docs/REVIEW.md).

## Что нужно

- Claude Code с поддержкой плагинов.
- Go 1.26+. Бинарь собирается сам при первом вызове, примерно за 10 секунд.
- ffmpeg с libx264.
- [edge-tts](https://github.com/rany2/edge-tts): `pipx install edge-tts`. Ключи и аккаунты не нужны, нужна сеть.

Проверка окружения: `serious-animator doctor`.

## Установка

```bash
claude plugin marketplace add tazhate/serious-animator
claude plugin install serious-animator@serious-animator
```

Из локального клона - то же самое, только вместо `tazhate/serious-animator` путь к каталогу.

Для разовой пробы без установки: `claude --plugin-dir /path/to/serious-animator`.

## Как это работает

Скилл `animate` ведет Claude по шагам:

1. Пишет `animations/<тема>/storyboard.json`: сцены, в каждой 2-8 битов. Бит - одна фраза диктора и один элемент, который рисуется, пока она звучит.
2. Рисует `scenes/s01.svg` и дальше. У каждого элемента есть `data-beat` - номер бита, под который его рисовать. Атрибуты `data-spin`, `data-move`, `data-highlight`, `data-anim` добавляют вращение, движение по траектории, обводку и появление с пружинкой.
3. `serious-animator validate` проверяет все, что ловится до рендера: лимиты, пути, произнесена ли подпись в фразе, у всех ли элементов есть бит, не налезают ли иконки друг на друга, не вылезло ли что-то за кадр.
4. `serious-animator preview` сохраняет финальный кадр каждой сцены с пронумерованными рамками битов. Claude открывает PNG и правит раскладку.
5. `serious-animator render` озвучивает фразы, раскладывает клипы на шкале времени и кодирует MP4 одним проходом ffmpeg.

Как выглядит результат. Теплая бумага, линии с дрожанием и двойным штрихом, концы сужаются, как у маркера. Заливки заштрихованы. Элемент начинает рисоваться на слове, которым его называет диктор: edge-tts отдает время каждого слова. Сцена шире кадра (`viewBox` 3200x1800) включает камеру: она наезжает на каждый бит и в конце отъезжает на общий план. Между сценами свайп. Под голос можно подложить музыку, она приседает под речь, плюс тихие pop и whoosh. Итог нормализуется до -14 LUFS.

Пример готового проекта лежит в [examples/dns](examples/dns): три сцены, 12 битов, около 67 секунд.

## Команды

```
serious-animator validate [--json] DIR
serious-animator preview  [--quality Q] [--out DIR] [--beats=false] [--frames] DIR
serious-animator render   [-o FILE] [--quality Q] [--no-audio] [--no-music] [--no-sfx]
                          [--no-word-sync] [--roughness R] [--no-marker] [--jobs N] DIR
serious-animator voices   [--lang ru]
serious-animator doctor
```

Пресеты качества: `low` 854x480 20 fps, `medium` 1280x720 24 fps (по умолчанию), `high` 1920x1080 30 fps. `--roughness 0` отключает дрожание линий, по умолчанию 1. Кадры рендерятся параллельно, `--jobs` по умолчанию равен числу ядер, но не больше 8. Двухминутный ролик в 720p собирается секунд за 15. `preview --frames` пишет для сцен с камерой по картинке на каждый бит.

Озвучка кэшируется в `~/.cache/serious-animator/tts` по хэшу голоса и текста, рядом лежат тайминги слов (`*.words.json`). Правка рисунка и повторный рендер не ходят в сеть. Если edge-tts часть клипов не отдал, готовые остаются в кэше и следующий запуск докачивает только недостающие.

## Подводные камни

- edge-tts - неофициальный клиент к сервису Microsoft. Он отвечает `403` пачками и иногда несколько минут подряд не отдает конкретный голос (`NoAudioReceived`). 12 октября 2026 так себя вел `ru-RU-DmitryNeural`, поэтому для `ru` по умолчанию стоит `ru-RU-SvetlanaNeural`. Лечится повторным запуском или сменой `voice` в storyboard.
- В SVG нет градиентов, `defs`, `use`, маркеров стрелок и фильтров. Валидатор называет строку и подсказывает замену. Полный список - в [skills/animate/references/svg-style.md](skills/animate/references/svg-style.md).
- Открытый `path` без `fill="none"` по стандарту SVG заливается черным. Валидатор об этом предупреждает.
- Тайминги слов берутся через Python-библиотеку `edge_tts` тем интерпретатором, что указан в shebang у `edge-tts`. Если импорт не проходит, рисование стартует с начала фразы, а `doctor` пишет `warn words`.
- В шрифте Caveat нет `Δ` и прочей математики. Такие символы рисуются путями.

## Разработка

```bash
make test     # go vet + go test
make build    # бинарь в ./dist
make example  # рендер examples/dns без звука в ./out
```

Код:

| Пакет | Что делает |
|---|---|
| `internal/geom` | точки, аффинные матрицы, парсер path-данных, аппроксимация кривых, длина и префикс ломаной, штриховка |
| `internal/svgscene` | подмножество SVG в плоский список элементов с битами, текст через глифы шрифта, атрибуты анимации, траектории |
| `internal/project` | загрузка storyboard и все проверки |
| `internal/textmatch` | сравнение слов подписи и речи с учетом словоформ |
| `internal/ease` | кривые сглаживания |
| `internal/raster` | штрих с круглыми концами и с переменной шириной, заливка, маски, бумага, маркер |
| `internal/timeline` | шкала времени в сэмплах, привязка к слову, паузы, расписание элементов внутри бита |
| `internal/tts` | edge-tts, тайминги слов, кэш, ретраи |
| `internal/audio` | PCM, WAV, сведение звука в ffmpeg с приседанием музыки и нормализацией громкости |
| `internal/sfx` | синтез pop, whoosh, шороха маркера и музыкальной подложки |
| `internal/render` | подготовка сцен, камера, движение, параллельный рендер кадров, превью, вызов ffmpeg |

Код под лицензией MIT, см. [LICENSE](LICENSE). Шрифт Caveat (Impallari Type) встроен в бинарь, у него своя лицензия SIL OFL 1.1, текст в `assets/OFL.txt`.
